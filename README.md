
  # Mars Orbiter Mission Web Page

  This is a code bundle for Mars Orbiter Mission Web Page. The original project is available at https://www.figma.com/design/rHUwISzJ5zPUICGM3c47td/Mars-Orbiter-Mission-Web-Page.

  ## Running the code

  Run `npm install` to install the dependencies.

  Run `npm run build:r1` and `npm run build:r2`
  Run `npm start` to run the server
